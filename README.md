# SMN GYM - Premium Fitness & Strength Training Website

A responsive, dynamic website for **SMN GYM** featuring:
- 📱 **Mobile-First Responsive Design**: Optimized for smartphones, tablets, and desktops with a Light/Dark theme toggle.
- 💬 **WhatsApp Direct Connect**: Custom popup sending inquiries directly to the gym owner (+91 8892152766).
- 🤖 **Interactive Gym Information Bot**: Real-time assistance on timings, pricing, machinery, and trial passes.
- 🎬 **Sequential Workout Video Player**: Auto-advancing video playlist with custom playback controls.
- 🔒 **Owner Video Upload**: Secure video uploads protected by Owner PIN.
- 📊 **Member Registration**: Captures visitor leads and automatically logs them into a backend Excel file (`SMN_Gym_Members.xlsx`).

---

## 🚀 Quick Start (Local Run)

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the web server:
   ```bash
   npm start
   ```
3. Open in your browser:
   `http://localhost:3000`

---

## 🌐 Deploying Online (Free Cloud Hosting)

This application runs on Node.js. To make it accessible worldwide with the live Excel lead sync and video player:
1. Connect this GitHub repository to [Render](https://render.com) (or Railway / Koyeb).
2. Choose **Web Service** -> **Node.js Environment**.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Click **Deploy** to get your free live public link (`https://smn-gym.onrender.com`).
